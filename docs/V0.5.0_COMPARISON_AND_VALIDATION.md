## 통합 결과

- WP1의 원시 전사 보존, 실제 점수 계약, 디스크 backlog, 저장 후 UI 발행, 실패 queue 보존, 버전형 재전사 migration을 포함했다.
- v0.4.1의 KRDS 화면, 실시간 전사·요약, 받아쓰기, YouTube 내부 플레이어, 한국어 모델 오프라인 동봉, 요약 모델 선택과 OpenAI 호환/OpenCodex 연결을 유지했다.
- 버전을 패키지, Cargo, Tauri 설정과 lock 파일에서 `0.5.0`으로 맞췄다.
- Windows GPU 감지는 CUDA 환경변수 존재가 아니라 `nvcuda.dll`과 `nvidia-smi`의 실제 장치 응답을 확인한다.
- native Whisper를 CUDA로 컴파일하고 실제 장치가 없으면 CPU 폴백 대신 명시적 오류를 반환한다.
- CUDA 12.3 실행 DLL을 설치 리소스로 동봉해 사용자 PC에 개발용 CUDA Toolkit을 요구하지 않는다.
- v0.4.1에서 이미 적용된 10개 SQL migration 바이트와 체크섬을 그대로 유지하고, v0.5.0 스키마는 새 `20260928000000` migration으로만 추가했다. 기존 DB로 실제 실행해 호환성을 확인했으며, 과거 migration 변경을 막는 회귀 테스트를 추가했다.
- 설치 검증기는 CUDA DLL 3개와 배포 고지 파일이 EXE 옆에 설치되고 빌드 입력 해시와 일치하는지 확인한다.
- 화면의 원본 프로젝트 외부 링크를 Stream-Record GitLab 링크로 변경했다. 기존 앱 식별자와 레거시 경로 문자열은 사용자 데이터 호환을 위해 유지한다.
