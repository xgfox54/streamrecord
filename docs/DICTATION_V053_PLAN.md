## 구현 계약과 영향도
useMeetingSession → useTranscriptCorrection → transcript-correction(분할/응답 검증) → generateText(모든 AI 요청 직렬화) → ko_generate correction → 기존 Ollama/사용자 프록시. 결과는 rows.ai_correction에 원문·모델·용어집과 함께 보관한다. rows.text와 reviewed_text는 변경하지 않는다. JSON 자동복구/내보내기에 포함한다. 원문 TXT는 항상 최초 인식 그대로이며 보정 TXT를 별도 제공한다. 회의록은 기존 원문/사람 검토본 규칙을 보존한다.

모델 미연결/보정 해제/오류 시 원문이 계속 보인다. 자동 보정은 사용자가 전송 위치를 보고 켠다. 미확정 행은 보내지 않는다. 긴 행은 분할하되 전체 결과 성공 후 행 단위 저장. 잘못된 JSON/ID/빈 응답/과도한 축약/수치 변경은 거절. 세션·모델·용어집 변경, 해제, unmount 이후 늦은 응답은 반영하지 않는다. 실패는 자동 반복하지 않고 재시도 버튼 제공.

받아쓰기는 모든 구간에 접근 가능하며 200구간 페이지+전체 검색으로 긴 회의를 처리한다. 기본 최신 페이지, 과거 읽기 중 자동 이동 금지. 녹음 설정은 상단 접기. 텍스트 모드는 원문/보정본, 각 보정의 최초 원문 공개. 공유 노트의 읽기 구조를 참고하며 Jeju 색/글꼴/접근성/자체 아이콘 유지.
