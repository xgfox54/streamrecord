# Jeju UI 및 전사 검토 개선

기준: 로컬 v0.5.1 (기존 DB 초기화 수정 7개 파일 보존).
디자인 정본: https://gitlab.aigov.go.kr/memory365/jeju-style-ui-ux
참조 SHA: 3fe4fc321dabb03f3fff42c06e2b9004636b8c0f.

## 분석
- 실제 10분 테스트에서 88개 전사 구간이 저장됐다. 일부 오인식과 인접 문장 반복이 존재한다. 정확도 수치나 원인을 추정해 완료 처리하지 않는다.
- 준비 폼과 상태 패널 아래에 실시간 결과가 밀린다. 첫 사용자는 시작 전 확인사항과 다음 행동을 찾기 어렵다.
- YouTube 화면이 조건부 마운트되어 다른 화면으로 이동하면 iframe이 파괴된다. 녹음은 계속되는데 영상 소리는 멈출 수 있다.
- 원음이 연결되지 않으면 구간 듣기가 비활성화되지만 준비 동작이 접힌 고급 영역에 있다.
- 색은 기존 제주 3색과 유사하지만 정본 토큰·타이포·패널 반경의 직접 연동이 없다.

## 실행 계획
1. [완료] 사용자 수정, 현재 프로세스, 디자인 정본과 기존 흐름 확인.
2. [완료] DESIGN.md를 정본 토큰과 초보자 흐름으로 갱신. 재사용 상태/단계/준비 컴포넌트 적용.
3. [완료] 영상 유지, 반복 확인 표시와 원음 연결 안내를 회귀 테스트로 검증.
4. [완료] 타입 검사·프런트엔드 빌드, 실제 브라우저의 화면/키보드/반응형 검증.
5. [완료] 네이티브 빌드·설치파일·설치본 실행 검증. 배포는 성공 결과가 확인된 단계만 보고.

## 보존 조건
한국어 음성 모델 동봉, 최초 설치 시 요약 모델 없음, 실제 입력 장치 선택, 녹음/전사 원문, 기존 사용자 데이터와 아이콘 정본을 보존한다. 중복 의심 표시가 원문·S ID·요약 근거를 변경해서는 안 된다.
