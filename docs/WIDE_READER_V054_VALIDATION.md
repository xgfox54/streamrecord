# v0.5.4 공통 실시간 전사 영역

## 구현
- 회의 녹음과 YouTube 전사에서 받아쓰기의 reader/conversation/utterance/meta/empty CSS를 직접 재사용한다. 전체 본문 폭, 60vh·최소 30rem, 19px·줄간격 1.85. 좁은 화면은 기존 받아쓰기의 17px 크기다.
- 회의 준비 옵션은 상단 접기. 동의·시작/중지는 표시 유지. YouTube 전사는 영상 카드 아래 독립 패널, 요약은 그 아래다.
- 녹음·원문·AI 보정·동봉 모델·영상 iframe 생명주기는 변경하지 않았다. 새 외부 의존성 없음.

## 자동 검사와 실제 추론
- 프런트엔드 47개, React 세션 30개, 배포 도구 27개, Rust 30개 통과. TypeScript와 cargo check 통과.
- 한국어 기본 모델 small-q5_1의 오프라인 로드 통과. 기존 승인된 18.686초 WAV를 실제 CUDA로 0.802초에 추론(RTF 0.0429). 새 물리 장치 녹음 시험과 구분한다.
- 아이콘 정본 및 파생 32개 파일 해시, 모델 SHA256 검증 통과.

## 화면과 조작
- 실제 production Chrome 렌더링 40장: outputs/wide-reader/current/qa.json 및 image-integrity.json. 네이티브 명령과 YouTube 응답은 시뮬레이션했다.
- 받아쓰기·회의 녹음·YouTube의 reader 크기 일치: viewport 375 → 309×576px, 768 → 678×576px, 1280 → 934×576px, 1440 → 1094×576px. 세로 viewport 960px 기준.
- 7개 메뉴의 375/768/1280px와 실시간 3개 메뉴의 1440px에서 가로 넘침 없음, axe WCAG 2A/AA·2.1AA 위반 없음. 녹음 옵션 펼치기, 125% 확대 리플로 검사 통과.
- 합성 100구간을 사용한 시작·추가 이벤트·수동 스크롤 유지·최신 문장 이동·키보드 포커스 검사 통과. 메뉴 왕복 시 YouTube iframe 객체 유지. JS 오류 없음.
- 독립 코드/연동 검토와 화면/CJK 검토 모두 PASS. 각 보고서와 정확한 소스 해시는 outputs/wide-reader/review-ledger.json에 기록. 실제 설치본에서도 회의 녹음/YouTube 전사/받아쓰기를 열고, 옵션 펼치기와 스크롤 및 넓어진 독립 전사 창을 확인했다. 증거: outputs/wide-reader/native-qa.json.

## 설치와 배포
- 네이티브 release 앱 빌드와 모델 포함 NSIS 생성 완료. 패키지 검증 138 통과·실패 0. 설치파일 522,174,792 bytes, SHA256 92700a491d60731f0b241040a5c62848d5f82f464b8064e7e8fb42133c53976b.
- 기존 설치를 백업한 뒤 v0.5.4로 교체 완료. 설치 EXE와 동봉 한국어 모델 해시가 패키지와 일치. 기존 세션 88구간·회의록 등 전체 필드와 파일 바이트가 설치 전과 동일. 설치본을 실행해 변경된 화면 확인 완료.
- GitLab/Google Drive는 v0.5.3 게시본 유지. v0.5.4는 이번 UI 변경 요청에서 외부 게시하지 않았다.

## 검증 범위
LSP는 호출 작업 경로 밖 저장소 제한으로 실행 불가. 실제 소스의 TypeScript 컴파일 검사로 오류를 확인했다. Lighthouse 점수·장시간 녹음·외부 공급자별 추론은 이 레이아웃 변경의 검증 완료 항목에 포함하지 않는다.
