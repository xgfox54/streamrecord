## 실사용 및 보안 수정

- 기존 빈 proxy store의 암묵적 기본 주소 이관 누락: 실패 먼저 재현 후 18회귀 PASS. 신규 설치는 연결을 만들지 않고 삭제한 프로필은 재생성하지 않는다.
