## 별도 검증 상태
- Windows 네이티브: Rust 검사·27개 테스트, 실제 동봉 모델 오프라인 로딩, 실제 CUDA 추론 통과. 18.686초 승인 음성을 1.095초에 처리한 단일 테스트이며 정확도 벤치마크는 아님. 설치파일 빌드·NSIS CRC·SHA-256·소스 일치 확인 완료. 패키징 검증 126개 통과. 최종 결과는 outputs/korean-bundled-0.5.2/package-result.json 참조.
- 설치본 교체: 기존 0.5.1 설치 폴더를 백업하고 0.5.2 설치. 실행파일과 동봉 모델의 SHA-256이 패키징 결과와 일치. installation-result.json 참조.
- 실사용 녹음: 설치된 0.5.2에서 실제 Stereo Mix 입력으로 승인된 12.630초 WAV 재생·녹음. 시작 3.956초, 중지 전 실시간 4구간 표시, 중지 후 4구간 저장, JS 오류 0. api_get_transcript_config 조회 성공. native-ui-result.json 참조.
- 영상: 실제 YouTube 플레이어 로딩 및 iframe 유지 확인. 추가로 음소거 재생 중 메뉴를 이동하고 돌아왔을 때 52.530초에서 56.150초로 계속 진행, paused=false 확인 후 정지. native-youtube-result.json, native-youtube-playback-result.json 참조. 10분 전체 녹음 재검증은 이번 빌드에서 수행하지 않음.
- 종료·복원: 실제 UI의 저장하고 완전히 종료 동작 성공. 테스트 결과는 별도 보관하고 기존 제목·전사 88구간을 복원해 재시작 후 동일성 확인. 사용자 세션 3에서 앱 실행 중. 테스트용 디버그 포트는 해제.
- 오디오 상태: 일시적으로 20%로 조절한 출력 음량을 원래 약 2.003%로 복원. 다른 앱 세션의 원래 음소거 상태 복원. 주변 마이크는 사용하지 않음.
- 설치된 앱이 cudart64_12.dll, cublas64_12.dll, cublasLt64_12.dll을 설치 폴더에서 적재한 것을 실행 중 확인.
- GitLab·Google Drive 배포: 이번 변경은 아직 배포하지 않음.

## 한계
이 변경은 음성모델의 인식 정확도를 개선했다고 주장하지 않는다. 전사 반복의 추론 원인을 확정하지 않았으며, 실제 반복 발언과 오인식을 원음으로 검토하는 도구를 제공한다. 사용자별 요약 계정의 실제 연결·요약 응답은 별도로 검증해야 한다.

## 발견 및 처리
- 반복 필터가 렌더 목록에 적용되지 않던 구현 오류를 실제 브라우저 테스트로 발견하고 수정.
- 화면 제목에 포커스를 주며 상단 메뉴가 스크롤되는 문제를 preventScroll 및 화면 전환 시 스크롤 초기화로 수정.
- 모바일 캡처는 실제 workspace 스크롤 컨테이너를 사용하도록 고치고, 모의 영상 HTML의 UTF-8·대비 오류를 수정해 재촬영. 제품 오류와 증거 오류를 구분.
- 최초 패키징 시 Tauri가 Cargo.toml을 CRLF에서 LF로 바꿔 소스 일치 검증이 중단됨. 내용 변경이 없음을 각 줄바꿈의 해시로 확인하고, LF 상태에서 전체 패키징 검증을 다시 실행해 통과. 실패 기록은 prior-*.json에 보존.
- 실제 음성에서 Stream-Record 고유명사가 ‘스트리밀 레코드’로 인식됨. 모델 정확도 개선 완료로 처리하지 않음.
