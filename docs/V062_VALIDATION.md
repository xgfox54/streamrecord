# v0.6.2 영상·전사 화면 개선 검증

- 구현: 상시 펼친 YouTube(최대 1280×720, 작은 창 16:9), 영상 아래 조밀한 원문/보정본, 고정 위치 녹음 옵션, 시간별 요약과 빨간 확인 문장, 8개 분야별 용어집.
- 요약은 저장 원문을 보존하고 화면에서만 [확인 필요]를 제거한다. 단일 시각과 시간 범위를 별도 줄로 표시한다. 표시기는 AI가 표시한 확인 문장을 강조하며 자체 오류 판별 엔진은 아니다.
- 용어집은 공식 의회 안건 기반 편집 분류이며 자동 전체 회의 분석 또는 음성 인식 효과 검증으로 보고하지 않는다. 자세한 출처는 GLOSSARY_SETS_V062.md.
- 타입 검사, Rust 검사와 패키지 사전 회귀 247건 통과. 요약 표시 10건과 용어집 10건 포함.
- 실제 동봉 small-q5_1 모델: 네트워크 없이 해시 검증·적재 성공. 검증용 18.686초 음성의 CUDA 추론 0.938초, 100자 출력. 새 마이크/장치 녹음 검증은 수행하지 않았다.
- 실제 Chrome 브라우저: 108캡처, 27개 axe 상태 위반 0, pageerror 0. 1920px에서 1280×720을 실측하고 375/768/1280 반응형 및 영상/전사 동시 표시 검증. native·음성·AI·영상 콘텐츠 경계는 테스트 대역.
- 독립 시각·코드 검토 A/B 통과: outputs/ui-video-v062/review-range-A.md, review-range-B.md. 빌드 입력 667개 해시 고정 및 일치 확인.
- 설치파일 생성·CRC/해시 검사 완료, 전체 248건 통과·실패 0. 기존 위치에 v0.6.2 설치 완료. 설치 EXE는 패키지의 installedExeSha256와 일치한다. 빌드 EXE와는 Tauri NSIS bundle type marker 3바이트만 다르며 패키징 단계에서 검증했다.
- 설치 전 현재 회의 94구간과 최근 요약을 정상 종료로 저장하고, 마지막 세션 및 기록 3개를 outputs/ui-video-v062에 백업했다. 이전 백업으로 사용자 데이터를 되돌리지 않는다.
- 설치본 수동 UI: 실제 YouTube 임베드 로드, 상시 펼친 영상과 전사 동시 표시, 원문/보정본 탭 전환, 시간 범위 줄 분리, 빨간 확인 문장 및 안내문, 녹음 옵션 위치 고정, 8개 용어 세트, 설정의 버전 0.6.2 확인. 증거: outputs/ui-video-v062/native 및 final-verification.json. 실영상 재생·새 녹음·외부 AI 요청은 이번 화면 검사 범위 밖.
