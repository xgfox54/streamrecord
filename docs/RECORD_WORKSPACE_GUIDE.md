# 기록 중심 화면 사용법

1. 왼쪽 **새 기록**을 누르고 제목을 입력합니다. 작은 창에서는 상단 기록 목록 버튼으로 보관함을 펼칩니다.
2. **마이크 · PC 소리 · YouTube · 음성 파일** 중 입력을 선택합니다. 장치와 전문 용어는 녹음 옵션에서 설정합니다.
3. 녹음·처리 권한을 확인한 뒤 시작합니다. YouTube는 링크를 불러오고 녹음을 시작한 다음 플레이어를 재생합니다.
4. **대화**에서 실시간 원문과 AI 보정본을 전환합니다. AI 보정 설정에서 연결 모델과 전송 위치를 확인하고 자동 보정을 켭니다. 원문 함께 보기와 전체 검색을 사용할 수 있습니다.
5. 과거 문장을 읽는 동안 자동 이동을 멈추며, 새 문장 버튼으로 최신 위치에 돌아갑니다. 집중 모드는 기록 목록과 요약을 숨겨 읽는 폭을 넓힙니다.
6. 녹음 종료 후 **회의록**에서 요약 모델을 선택해 생성·편집·저장합니다. 화자 구분은 대화의 화자 구분 메뉴에서 원음을 연결한 뒤 실행합니다.

저장된 기록을 누르면 현재 작업을 먼저 저장하고 선택한 기록을 엽니다. 녹음·변환·AI 처리·저장 중에는 전환이 잠깐 제한됩니다. 저장 실패 시 현재 기록을 지우지 않습니다. 기존 마지막 작업은 보관함에 등록되며, 이전에 개별 내보낸 파일을 자동으로 수집하지는 않습니다.

YouTube 영상의 크기를 바꾸거나 접어도 같은 플레이어를 유지합니다. 영상과 알림 등 다른 PC 소리도 Stereo Mix에 함께 들어올 수 있으므로 필요한 소리만 재생하세요.
