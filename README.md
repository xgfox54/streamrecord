# Stream-Record v0.7.8

GPU 가속, 녹음파일 처리 시간 표시와 TXT 가독성을 개선했습니다. 원음과 기존 기록을 보존합니다.

회의록 읽기 화면, 받아쓰기·요약 이동, AI 상태와 설정 구조를 개선했습니다. 원음과 기존 기록을 보존합니다.

분야별 단어장을 약 3,000자로 확장하고 원문·보정 모델 표시를 개선했습니다. 단어장은 AI 보정에서만 사용하며 원문 받아쓰기에는 전달하지 않습니다.

단어장은 AI 보정에서만 사용하며 최초 받아쓰기와 원음 복구에는 전달하지 않습니다. 영상 제목·회의 내용 기반 자동 선택을 유지하고 업데이트 실행 실패 안내를 개선했습니다.

AI 보정이 숫자나 문장 길이 차이로 보류되면 ‘무시하고 보정 처리’로 AI 문장을 적용할 수 있습니다. 최초 원문은 보존되며, 안내문 글자 크기는 2pt 줄였습니다.

긴 받아쓰기 내용을 한 스크롤 창에서 읽을 수 있습니다. AI 요약과 안내 문구에 줄바꿈을 넣고 원문 배경을 연한 노란색으로 구분합니다. 회의록 생성 진행 상황과 오류를 버튼 옆에 표시하며, 같은 내용과 모델로 다시 시도하면 저장된 묶음을 재사용합니다.

v0.6.7은 PC 소리·YouTube 화면에서 꺼진 스테레오 믹스를 앱에서 켤 수 있고, 녹음 시작·전사 진행을 회전·점 애니메이션으로 보여 주며, YouTube 전사 도구줄의 '전사 설정' 위치를 고정하고 '대화 내용 검색'을 항상 표시합니다. v0.6.6의 소리 선택·장치·녹음 시작·받아쓰기 흐름과 버전 표시를 유지합니다. PC 소리와 YouTube는 실제 스피커·헤드폰 소리를 직접 녹음합니다. X 버튼의 창 닫기와 전체 종료 처리를 분리합니다. 녹음·처리 중에도 X를 누르면 창만 트레이로 숨기며, 트레이 아이콘을 왼쪽 클릭하면 다시 열립니다. 오른쪽 클릭 메뉴나 설정의 ‘Stream-Record 종료’로 저장 후 완전히 종료합니다.

v0.6.4 CPU 호환 배포판은 한국어 Whisper 모델과 저장 음성 화자분리 자료를 동봉합니다. 전사는 CPU에서 처리하며 CUDA 가속을 사용하지 않습니다. 이 PC의 검토 프로필 문서 경로 초기화·TXT 내보내기를 수정했고, 이관된 VAD 창 처리·내구성 있는 대기열·원음 체크포인트·UTF-8 한국어 처리 개선을 포함합니다. 원음·최초 전사·검토본을 유지합니다. 장시간 전사 공백의 정확도 평가는 아직 완료하지 않았습니다.

Windows x64용 한국어 녹음·전사·회의록 앱입니다. 마이크 또는 실제 스피커·헤드폰 출력 장치 하나를 사용하며, 한국어 음성 인식 모델을 설치파일에 포함합니다. 기록 목록·대화·회의록과 선택적 실시간 요약을 한 작업 화면에서 사용하고 Jeju 디자인 가이드를 적용했습니다. YouTube는 상시 펼친 최대 1280×720 영상과 그 아래 원문/AI 보정본을 표시합니다. v0.6.3은 숫자·길이 보호에 걸린 구간의 원문과 확인 사유를 유지하면서 나머지 보정을 계속하며, 유효한 AI 보정본을 실시간 요약에 반영합니다.

소스·검사·설치파일 생성·설치본 교체·GitLab 게시 결과는 각각 구분합니다. 이번 배포의 확인 결과는 설치파일 옆 `BUILD_VERIFICATION.json`, `RELEASE_VALIDATION.md`, `SOURCE_MANIFEST.json`, `SHA256SUMS.txt`에서 확인하세요. 이전 버전 검사 자료는 해당 버전 결과이며 이번 배포 검증을 대신하지 않습니다.

## 설치

[지정 GitLab 릴리스](https://gitlab.aigov.go.kr/memory365/streamrecord/-/releases/v0.7.8)에서 온라인 설치 EXE 또는 전체 설치파일 조각·복원 스크립트를 받습니다. 온라인 설치 EXE의 기존 `online-cpu` 파일명은 이전 앱의 업데이트 검증과 호환되도록 유지하지만 실제 설치 내용은 Vulkan GPU 가속판입니다. 이전 버전을 사용 중이면 녹음·받아쓰기·요약을 끝내고 **설정 → Stream-Record 종료**로 완전히 종료한 뒤 설치합니다. 창의 X는 트레이로 숨기는 동작입니다.

설치 프로그램은 미서명입니다. SHA-256은 파일 무결성 확인이며 게시자 코드 서명을 대신하지 않습니다. Windows WebView2 등 선행 런타임이 없는 PC에서는 최초 런타임 설치에 인터넷이 필요할 수 있습니다. 음성모델의 오프라인 사용과 선행 런타임 설치는 별개입니다.

기존 사용자 설정·녹음·모델은 삭제하지 않습니다. 앱 식별자 `local.meetily.korean.workspace`, 기존 모델/복구 경로와 문서 폴더의 `Stream-Record/Exports`를 유지합니다.

## 녹음

1. **현재 기록**에서 마이크, PC 소리 또는 YouTube를 선택합니다. 원문과 AI 보정본은 **받아쓰기**, 완성된 기록은 **회의록**에서 확인합니다.
2. 회의 제목과 실제 입력 장치를 확인합니다. 회의 용어는 상세 설정에서 입력합니다.
3. 참여자에게 녹음을 알리고 처리 권한 확인란을 선택합니다.
4. **녹음 시작**을 누릅니다. 모델 확인·적재 중에는 녹음하지 않습니다. 실제 시작 성공 후 녹음 시간과 상태가 표시됩니다.
5. **녹음 중지** 후 마지막 음성 처리와 저장이 끝날 때까지 기다립니다. 남은 구간은 사용 가능한 GPU 또는 CPU로 처리하며, 그동안 '마지막 음성 저장 중…'이 표시됩니다. 처리 시간은 PC와 녹음 내용에 따라 달라집니다. 다른 화면으로 이동해도 세션은 유지됩니다.

PC 소리와 YouTube는 Windows WASAPI로 선택한 스피커·헤드폰의 재생 소리를 녹음합니다. 스테레오 믹스가 없어도 사용할 수 있습니다. 시작 전 화면에 보이는 장치를 확인하고 녹음·처리 권한을 체크하세요. 장치가 없으면 소리 장치 새로고침을 누르고 다시 선택하세요. 미존재 장치를 만들거나 다른 마이크로 자동 대체하지 않습니다. YouTube는 링크를 불러온 뒤 영상 아래 오른쪽의 영상 소리 녹음 시작 → 영상 재생 → 중지 및 저장 순서로 사용합니다. YouTube 영상은 앱 내부 플레이어에서 재생하며 영상을 다운로드하지 않습니다. 재생 길이만큼 처리 시간이 필요하고 음소거하면 해당 소리를 전사할 수 없습니다.

## 실시간 받아쓰기와 요약

녹음 중 부분 문장은 실시간 전사 창의 마지막 행에서 계속 교체되고, 음성 인식이 확정한 문장은 시간과 함께 누적됩니다. 사용자가 과거 문장을 읽으면 자동 이동을 멈추고 **최신 문장**으로 복귀할 수 있습니다. 전체 원문과 검토본은 **전체 전사**에 계속 보존됩니다.

**받아쓰기**의 녹음 옵션은 화면 상단에서 접고 펼칩니다. AI 모델과 전송 위치를 확인한 뒤 자동 보정을 켜면 확정된 문장을 보정합니다. 최초 원문·수동 검토본·AI 보정본을 별도 보존하고, 원문/보정본 전환, 원문 함께 보기, 검색, 한 창의 전체 대화 스크롤, 각각의 TXT 저장을 제공합니다. 자동 보정과 화자 구분은 처음 실행할 때 켜져 있으며 사용자가 선택을 바꾸면 다음 실행에도 유지됩니다. AI 연결 없이도 원문 전사는 가능합니다. AI는 원음을 직접 확인하지 않으므로 보정본을 원음과 대조해야 합니다.

실시간 요약은 기본적으로 꺼져 있습니다. 사용자가 화면에서 켜면 확정 전사만 선택한 모델로 보내 현재까지의 요약을 갱신합니다. 로컬 모델은 이 PC에서 처리하고, OpenAI 호환/OpenCodex 연결 모델은 설정한 서버로 전사문을 전송합니다. 요약 모델이 없어도 녹음·받아쓰기는 동작합니다.

**YouTube 전사**에서는 주소 검증 후 `youtube-nocookie.com` 내부 프레임을 표시하고, 그 아래에서 전사와 요약을 함께 읽습니다. 별도 영상 창을 열지 않습니다.

## 동봉 한국어 모델

기존에 선택한 정상 다국어 Whisper 모델을 우선 유지합니다. 적합한 모델이 없으면 설치 리소스의 `small-q5_1`을 SHA-256·크기로 검증하고 등록·적재합니다. 영어 전용 `.en` 모델을 자동 선택하지 않습니다. 파일이 없거나 손상되면 자동 다운로드로 전환하지 않고 오류를 표시합니다.

동봉 모델은 `ggml-small-q5_1.bin` 190,085,487바이트이며, `manifest.json`과 `WHISPER-LICENSE.txt`를 함께 배포합니다. 출처는 고정 revision의 [ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp)입니다. 실제 기준 해시는 `app/frontend/src-tauri/src/whisper_engine/model_integrity.rs`와 동봉 manifest에 기록됩니다. 설치 리소스와 사용자 모델 폴더 각각에 저장하므로 추가 디스크 공간이 필요합니다. 요약용 대형 언어모델은 동봉하지 않습니다.

v0.7.8 Windows x64 설치본은 Vulkan GPU 가속을 포함합니다. 사용 가능한 GPU가 없거나 초기화에 실패하면 CPU로 처리합니다. CUDA Toolkit 설치는 필요하지 않으며 Vulkan 지원 그래픽 드라이버가 필요합니다. 실제 검증은 RTX 4060과 GTX 1660 Ti의 짧은 한국어 샘플로 수행했으며 한 시간 파일 완료 시간은 아직 측정하지 않았습니다.

녹음파일 받아쓰기는 모든 구간 처리와 저장이 끝난 뒤 텍스트를 표시합니다. 처리 중 경과 시간과 예상 전체·남은 시간을 표시하며, 첫 구간에서는 계산 중으로 표시합니다. 예상 시간에는 별도 AI 보정 시간이 포함되지 않습니다. AI 보정본 TXT에는 보정된 문장 또는 직접 수정한 문장만 저장하며 최초 원문을 섞지 않습니다. TXT 구간 사이에는 빈 줄을 넣습니다.

## 전사 검토와 회의록

전체 원문·검토본을 하나의 스크롤 창에서 검색하고 읽을 수 있습니다. 검토본은 별도 `reviewed_text`에 저장하며 최초 원문을 덮어쓰지 않습니다. 과거 구간 읽기나 편집 중 자동 이동을 멈추고 최신 구간으로 복귀할 수 있습니다. 근거 ID는 화면 정렬/필터와 무관하게 원래 구간을 가리킵니다.

원음은 파일 연결·SHA-256·시간정보 확인 후 구간 단위로 재생합니다. 저장 음성 재전사는 24초 단위 체크포인트로 이어가며 원음·모델·용어 변경 시 기존 체크포인트를 재사용하지 않습니다. 이는 강제 종료된 실시간 녹음의 자동 복원을 보장하는 기능이 아닙니다.

회의록은 구간별 결정·제안·조치·수치·미결 사항을 추출하며 존재하는 원문 ID와 정확한 인용을 검사합니다. 담당자·기한을 추측하지 않습니다. 결과는 초안이며 사람이 원음과 대조해야 합니다. 취소는 진행 중인 구간 처리 후 이루어지고 실패한 중간 결과를 완성본으로 표시하지 않습니다.

- TXT: 최초 전사 원문 또는 별도로 선택한 AI 보정본
- JSON: 원문·검토본·회의록·재개 상태
- Markdown: 회의록

## AI 연결 범위

AI 연결 화면에서 다음 경로를 각각 설정합니다.

- 이 PC의 Ollama 및 사용자가 선택 다운로드한 내장 GGUF 모델
- 공식 Sign in with ChatGPT OAuth: 브라우저에서 직접 로그인하며 OpenCodex·Codex Desktop은 필요하지 않습니다. 실제 계정 사용 가능 여부와 모델은 공식 서비스 응답에 따릅니다.
- OpenCodex 연결, OpenClaw 연결, OpenCode 연결 및 기타 OpenAI 호환 서버
- OpenRouter 서비스, OpenAI API 키, Anthropic API 키

OpenRouter는 호스팅 서비스입니다. OpenClaw·OpenCode는 서로 다른 프로토콜과 권한 조건을 사용합니다. 설정에서 실제 전송 주소를 확인하고 모델 목록 조회와 짧은 실제 응답 시험을 따로 실행하세요. localhost 서버도 외부 모델로 중계할 수 있습니다. 인증정보는 Windows 사용자 DPAPI로 보호하며, 연결 설정 변경 시 이전 모델 선택을 그대로 실행하지 않습니다.

Claude·Antigravity 개인 계정의 직접 로그인은 지원 완료로 표시하지 않습니다. 외부 연결 서버를 통한 사용과 공식 직접 인증은 별개입니다. 로컬 요약 모델은 최초 설치 시 없으며 녹음·전사는 요약 모델 없이 동작합니다.

## 화자와 중단된 작업

원음을 연결하고 녹음이 끝난 뒤 **화자 분석**을 실행하면 동봉 Nemotron 런타임이 저장된 전체 음성을 분석합니다. 원문을 변경하지 않고 확인된 시간 겹침에 화자 번호를 표시합니다. 동시에 말하거나 시간정보가 부족한 구간을 한 명으로 추측하지 않습니다. 현재 녹음 중의 실시간 화자 스트리밍은 지원하지 않습니다.

전체 전사에서 중단된 녹음 작업을 확인하고 미처리 구간을 다시 처리할 수 있습니다. 복구 결과를 먼저 확인한 뒤 새 작업에 적용하며 기존 대화를 보관합니다. 디스크 공간 고갈이나 원본 파일 손상까지 복구를 보장하지 않습니다.

실시간 요약은 이전 요약과 새 확정 구간을 누적하며 이력을 보존합니다. 모델·계정·용어·이미 요약한 원문이 바뀌면 이전 체크포인트를 재사용하지 않습니다.

## 개발과 빌드

Node.js 20 이상, npm, Rust/Cargo, Visual Studio C++ Build Tools, CMake, LLVM/Clang이 필요합니다. `app/`이 정본이며 `overlay/`와 원래 Meetily 저장소는 참고 자료입니다. 사용자 변경 위에 overlay를 재적용하거나 원본 커밋으로 강제 되돌리지 않습니다.

```powershell
# 프로젝트 루트
node setup.mjs doctor
# 프런트엔드
cd app/frontend
npm run test:stream-record
node tests/stream-record-ui.cjs
npm run typecheck
# 동봉 모델·실행 자료를 준비한 뒤 CPU판 생성
npm run tauri -- build --no-bundle --config ../../tools/tauri.cpu-release.conf.json -- --locked
npm run tauri -- bundle --config ../../tools/tauri.cpu-release.conf.json --bundles nsis --verbose --no-sign
```

빌드 결과는 Cargo target의 `release/`와 `release/bundle/nsis/`에 생성됩니다. 한국어 모델과 바이너리 자원은 소스 ZIP에 포함하지 않으며, 고정 해시로 준비한 자원을 설치파일에 동봉합니다. 이번 CPU 배포판은 CUDA DLL을 제외하는 `tools/tauri.cpu-release.conf.json`을 사용합니다. 기존 `tools/package-korean-bundled.mjs`는 CUDA Toolkit과 GPU 검증을 요구하는 별도 GPU판 도구입니다. 실제 설치본 교체와 GitLab 게시는 별도 단계입니다.

## 검증 한계

자동 회귀검사, 실제 동봉 모델 적재, Tauri 화면 조작, 실제 마이크/Stereo Mix 녹음, 장시간 안정성은 서로 다른 시험입니다. 실행하지 않은 항목은 `NOT_RUN`으로 표시합니다. 자동 접근성 검사만으로 화면 낭독기·Windows 배율·고대비 모드 전체가 검증된 것으로 보고하지 않습니다.
