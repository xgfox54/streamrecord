# Stream-Record v0.6.3

Windows x64용 한국어 녹음·전사·회의록 앱입니다. 마이크 또는 실제 Stereo Mix 입력 하나를 사용하며, 한국어 음성 인식 모델을 설치파일에 포함합니다. 기록 목록·대화·회의록과 선택적 실시간 요약을 한 작업 화면에서 사용하고 Jeju 디자인 가이드를 적용했습니다. YouTube는 상시 펼친 최대 1280×720 영상과 그 아래 원문/AI 보정본을 표시합니다. v0.6.3은 숫자·길이 보호에 걸린 구간의 원문과 확인 사유를 유지하면서 나머지 보정을 계속하며, 유효한 AI 보정본을 실시간 요약에 반영합니다.

소스·검사·설치파일 생성·설치본 교체·GitLab 게시 결과는 각각 구분합니다. 현재 실행의 확인 결과는 [UI 수용 검사](docs/UI_ACCEPTANCE_REPORT.md)와 설치파일 옆 `BUILD_VERIFICATION.json`, `package-result.json`, `installation-result.json`, `deployment-result.json`을 확인하세요. 파일이 없거나 해당 단계가 미실행이면 완료된 것이 아닙니다.

## 설치

[지정 GitLab 릴리스](https://gitlab.aigov.go.kr/memory365/streamrecord/-/releases)에서 `Stream-Record-0.6.3-korean-bundled-windows-x64-setup.exe`와 `SHA256SUMS.txt`를 받습니다. 해당 버전 릴리스가 게시되기 전에는 내려받을 수 없습니다. 이전 버전을 사용 중이면 녹음·전사·요약을 끝내고 **설정 → Stream-Record 종료**로 완전히 종료한 뒤 설치합니다. 창의 X는 트레이로 숨기는 동작입니다.

설치 프로그램은 미서명입니다. SHA-256은 파일 무결성 확인이며 게시자 코드 서명을 대신하지 않습니다. Windows WebView2 등 선행 런타임이 없는 PC에서는 최초 런타임 설치에 인터넷이 필요할 수 있습니다. 음성모델의 오프라인 사용과 선행 런타임 설치는 별개입니다.

기존 사용자 설정·녹음·모델은 삭제하지 않습니다. 앱 식별자 `local.meetily.korean.workspace`, 기존 모델/복구 경로와 문서 폴더의 `Meetily-Korean/Exports`를 유지합니다.

## 녹음

1. **현재 기록**에서 마이크, PC 소리 또는 YouTube를 선택합니다. 원문과 AI 보정본은 **대화**, 완성된 기록은 **회의록**에서 확인합니다.
2. 회의 제목과 실제 입력 장치를 확인합니다. 회의 용어는 상세 설정에서 입력합니다.
3. 참여자에게 녹음을 알리고 처리 권한 확인란을 선택합니다.
4. **녹음 시작**을 누릅니다. 모델 확인·적재 중에는 녹음하지 않습니다. 실제 시작 성공 후 녹음 시간과 상태가 표시됩니다.
5. **녹음 중지** 후 마지막 음성 처리와 저장이 끝날 때까지 기다립니다. 남은 구간을 CPU로 전사하므로 녹음 길이와 비슷한 시간이 걸릴 수 있으며, 그동안 '마지막 음성 저장 중…'이 표시됩니다. 다른 화면으로 이동해도 세션은 유지됩니다.

PC 소리와 YouTube 전사는 Windows의 Stereo Mix 입력이 필요합니다. 미존재 장치를 만들거나 마이크로 자동 대체하지 않습니다. 장치가 없으면 Windows 소리 설정에서 활성화 후 새로고침하세요. 별도 시스템 오디오 트랙은 동시에 수집하지 않습니다. YouTube 영상은 앱 내부 플레이어에서 재생하며 영상을 다운로드하지 않습니다. 재생 길이만큼 처리 시간이 필요하고 음소거하면 해당 소리를 전사할 수 없습니다.

## 실시간 받아쓰기와 요약

녹음 중 부분 문장은 실시간 전사 창의 마지막 행에서 계속 교체되고, 음성 인식이 확정한 문장은 시간과 함께 누적됩니다. 사용자가 과거 문장을 읽으면 자동 이동을 멈추고 **최신 문장**으로 복귀할 수 있습니다. 전체 원문과 검토본은 **전체 전사**에 계속 보존됩니다.

**받아쓰기**의 녹음 옵션은 화면 상단에서 접고 펼칩니다. AI 모델과 전송 위치를 확인한 뒤 자동 보정을 켜면 확정된 문장을 보정합니다. 최초 원문·수동 검토본·AI 보정본을 별도 보존하고, 원문/보정본 전환, 원문 함께 보기, 검색, 페이지 이동, 각각의 TXT 저장을 제공합니다. 자동 보정은 시작 시 꺼져 있으며 AI 연결 없이도 원문 전사는 가능합니다. AI는 원음을 직접 확인하지 않으므로 보정본을 원음과 대조해야 합니다.

실시간 요약은 기본적으로 꺼져 있습니다. 사용자가 화면에서 켜면 확정 전사만 선택한 모델로 보내 현재까지의 요약을 갱신합니다. 로컬 모델은 이 PC에서 처리하고, OpenAI 호환/OpenCodex 연결 모델은 설정한 서버로 전사문을 전송합니다. 요약 모델이 없어도 녹음·받아쓰기는 동작합니다.

**YouTube 전사**에서는 주소 검증 후 `youtube-nocookie.com` 내부 프레임을 표시하고, 그 아래에서 전사와 요약을 함께 읽습니다. 별도 영상 창을 열지 않습니다.

## 동봉 한국어 모델

기존에 선택한 정상 다국어 Whisper 모델을 우선 유지합니다. 적합한 모델이 없으면 설치 리소스의 `small-q5_1`을 SHA-256·크기로 검증하고 등록·적재합니다. 영어 전용 `.en` 모델을 자동 선택하지 않습니다. 파일이 없거나 손상되면 자동 다운로드로 전환하지 않고 오류를 표시합니다.

동봉 모델은 `ggml-small-q5_1.bin` 190,085,487바이트이며, `manifest.json`과 `WHISPER-LICENSE.txt`를 함께 배포합니다. 출처는 고정 revision의 [ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp)입니다. 실제 기준 해시는 `app/frontend/src-tauri/src/whisper_engine/model_integrity.rs`와 동봉 manifest에 기록됩니다. 설치 리소스와 사용자 모델 폴더 각각에 저장하므로 추가 디스크 공간이 필요합니다. 요약용 대형 언어모델은 동봉하지 않습니다.

Windows x64 설치본은 native Whisper CUDA 빌드와 CUDA 12.3 실행 DLL을 함께 배포합니다. 별도 CUDA Toolkit 설치 없이 NVIDIA GPU 드라이버가 있는 지원 장치에서 동작하도록 구성하며, CUDA 빌드가 실제 NVIDIA 장치를 찾지 못하면 CPU로 조용히 전환하지 않고 오류를 표시합니다.

## 전사 검토와 회의록

전체 원문·검토본 검색과 300구간 단위 페이지 이동을 제공합니다. 검토본은 별도 `reviewed_text`에 저장하며 최초 원문을 덮어쓰지 않습니다. 과거 구간 읽기나 편집 중 자동 이동을 멈추고 최신 구간으로 복귀할 수 있습니다. 근거 ID는 화면 정렬/필터와 무관하게 원래 구간을 가리킵니다.

원음은 파일 연결·SHA-256·시간정보 확인 후 구간 단위로 재생합니다. 저장 음성 재전사는 24초 단위 체크포인트로 이어가며 원음·모델·용어 변경 시 기존 체크포인트를 재사용하지 않습니다. 이는 강제 종료된 실시간 녹음의 자동 복원을 보장하는 기능이 아닙니다.

회의록은 구간별 결정·제안·조치·수치·미결 사항을 추출하며 존재하는 원문 ID와 정확한 인용을 검사합니다. 담당자·기한을 추측하지 않습니다. 결과는 초안이며 사람이 원음과 대조해야 합니다. 취소는 진행 중인 구간 처리 후 이루어지고 실패한 중간 결과를 완성본으로 표시하지 않습니다.

- TXT: 최초 전사 원문 또는 별도로 선택한 AI 보정본
- JSON: 원문·검토본·회의록·재개 상태
- Markdown: 회의록

## AI 연결 범위

AI 연결 화면에서 다음 경로를 각각 설정합니다.

- 이 PC의 Ollama 및 사용자가 선택 다운로드한 내장 GGUF 모델
- 공식 Sign in with ChatGPT OAuth: 브라우저에서 직접 로그인하며 OpenCodex·Codex Desktop은 필요하지 않습니다. 실제 계정 사용 가능 여부와 모델은 공식 서비스 응답에 따릅니다.
- OpenCodex 연결, OpenClaw 연결, OpenCode 연결 및 기타 OpenAI 호환 서버
- OpenRouter 서비스, OpenAI API 키, Anthropic API 키

OpenRouter는 호스팅 서비스입니다. OpenClaw·OpenCode는 서로 다른 프로토콜과 권한 조건을 사용합니다. 설정에서 실제 전송 주소를 확인하고 모델 목록 조회와 짧은 실제 응답 시험을 따로 실행하세요. localhost 서버도 외부 모델로 중계할 수 있습니다. 인증정보는 Windows 사용자 DPAPI로 보호하며, 연결 설정 변경 시 이전 모델 선택을 그대로 실행하지 않습니다.

Claude·Antigravity 개인 계정의 직접 로그인은 지원 완료로 표시하지 않습니다. 외부 연결 서버를 통한 사용과 공식 직접 인증은 별개입니다. 로컬 요약 모델은 최초 설치 시 없으며 녹음·전사는 요약 모델 없이 동작합니다.

## 화자와 중단된 작업

원음을 연결하고 녹음이 끝난 뒤 **화자 분석**을 실행하면 동봉 Nemotron 런타임이 저장된 전체 음성을 분석합니다. 원문을 변경하지 않고 확인된 시간 겹침에 화자 번호를 표시합니다. 동시에 말하거나 시간정보가 부족한 구간을 한 명으로 추측하지 않습니다. 현재 녹음 중의 실시간 화자 스트리밍은 지원하지 않습니다.

전체 전사에서 중단된 녹음 작업을 확인하고 미처리 구간을 다시 처리할 수 있습니다. 복구 결과를 먼저 확인한 뒤 새 작업에 적용하며 기존 대화를 보관합니다. 디스크 공간 고갈이나 원본 파일 손상까지 복구를 보장하지 않습니다.

실시간 요약은 이전 요약과 새 확정 구간을 누적하며 이력을 보존합니다. 모델·계정·용어·이미 요약한 원문이 바뀌면 이전 체크포인트를 재사용하지 않습니다.

## 개발과 빌드

Node.js 20 이상, npm, Rust/Cargo, Visual Studio C++ Build Tools, CMake, LLVM/Clang이 필요합니다. `app/`이 정본이며 `overlay/`와 원래 Meetily 저장소는 참고 자료입니다. 사용자 변경 위에 overlay를 재적용하거나 원본 커밋으로 강제 되돌리지 않습니다.

```powershell
# 프로젝트 루트
node setup.mjs doctor
# 프런트엔드
cd app/frontend
npm run test:stream-record
node tests/stream-record-ui.cjs
npm run typecheck
# 프로젝트 루트에서 모델 포함 새 설치파일 생성
cd ../..
node tools/package-korean-bundled.mjs --build
```

모델을 포함한 새 설치파일, 원본/리소스 해시와 검증 기록은 `outputs/korean-bundled-0.6.0/`에 생성합니다. 실제 설치본 교체와 GitLab 게시는 별도 명령과 검증 단계입니다. 이전 버전 EXE를 새 UI 설치파일로 재사용하지 않습니다.
