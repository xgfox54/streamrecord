# Stream-Record v0.8.0

Windows x64용 한국어 녹음·받아쓰기·회의록 앱입니다. 마이크, PC에서 재생되는 소리, YouTube 영상의 소리와 저장된 음성 파일을 처리합니다. 한국어 Whisper 모델을 동봉하며, 요약과 AI 보정에 사용할 모델은 **AI 연결**에서 설정합니다.

## v0.8.0 변경 사항

- **기록 목록**: 제목 검색, 중요 표시, 검토할 기록·회의록 필터와 최근 기록 이어 보기를 제공합니다.
- **녹음 화면**: 경과 시간과 일시 정지·재개, 저장·취소 버튼을 표시합니다.
- **전사 편집**: 검토본과 최초 원문을 전환하고 원문을 함께 보면서 직접 수정합니다. 최초 원문은 덮어쓰지 않습니다.
- **녹음·저장 취소**: 녹음 중에는 **녹음 취소**, 녹음 중지 후 저장 중에는 **저장 취소**로 남은 처리를 중단합니다.
- **색상과 아이콘**: 제주 파랑 `#0173bc`, 초록 `#00a074`, 주황 `#f18101`과 새 3색 막대 아이콘을 적용했습니다. 앱·설치 프로그램·GitLab 프로젝트 아이콘에 같은 디자인을 사용합니다.
- 기존 데이터베이스의 SQL 체크섬을 고정하고 HTTPS·압축 처리 의존성을 보안 수정 버전으로 갱신했습니다.

전체 변경 이력은 [RELEASE_NOTES.md](RELEASE_NOTES.md)에서 확인합니다.

## 설치와 업데이트

[v0.8.0 릴리스](https://gitlab.aigov.go.kr/memory365/streamrecord/-/releases/v0.8.0)에서 `Stream-Record-0.8.0-online-cpu-win10-win11-setup.exe`를 받습니다. 온라인 설치 프로그램이 GitLab에서 동봉 설치 파일을 내려받고 SHA-256을 확인한 뒤 설치합니다.

파일 이름의 `online-cpu`는 기존 업데이트 경로와의 호환을 위해 유지한 이름입니다. 실제 동봉 앱은 **Vulkan GPU 지원 빌드**이며, 사용 가능한 GPU가 없거나 초기화에 실패하면 CPU로 처리합니다. CUDA Toolkit은 필요하지 않습니다. Vulkan 가속에는 지원 그래픽 드라이버가 필요합니다.

기존 앱에서는 업데이트 안내 버튼으로 설치합니다. 직접 설치할 때는 진행 중인 작업을 저장하거나 취소하고, **설정**의 **Stream-Record 종료**로 앱을 완전히 종료한 뒤 실행합니다. 창의 X 버튼은 앱을 트레이로 숨기는 동작입니다.

기존 사용자 설정·녹음·모델과 앱 식별자 `local.meetily.korean.workspace`를 유지합니다. 설치 프로그램에는 Windows 코드 서명이 없습니다. WebView2 등 선행 런타임이 없는 PC는 최초 런타임 설치에 인터넷이 필요할 수 있습니다.

## 새 녹음 시작

1. **나의 기록**에서 **새 녹음**을 누릅니다. 저장한 음성을 처리하려면 **파일 가져오기**를 선택합니다.
2. 기록 제목을 입력하고 **마이크**, **PC 소리**, **YouTube**, **음성 파일** 중 입력을 선택합니다.
3. 실제 녹음 장치를 확인하고 참여자에게 녹음을 알린 뒤 녹음·처리 권한 확인란을 선택합니다.
4. 녹음 시작 버튼을 누릅니다. 모델 확인·적재가 끝나고 녹음 시작에 성공하면 시간과 상태가 표시됩니다.
5. 필요하면 **일시 정지**와 **녹음 계속하기**를 사용합니다. 녹음을 마치고 최종 저장하려면 **저장하고 종료** 또는 상단 **녹음 중지**를 누릅니다.

녹음 화면의 **저장하고 종료**는 녹음을 끝내고 저장하는 동작입니다. 프로그램을 완전히 종료하는 동작과는 다릅니다. 다른 화면으로 이동하거나 창을 숨겨도 녹음은 계속됩니다. 화면의 파형은 녹음 상태를 보여 주는 애니메이션이며 실제 입력 음량 측정값은 아닙니다.

PC 소리와 YouTube는 선택한 스피커·헤드폰에서 재생되는 소리를 Windows WASAPI로 녹음합니다. 다른 영상이나 알림 소리도 함께 녹음됩니다. 스테레오 믹스는 필수가 아닙니다. YouTube는 링크와 영상을 불러온 뒤 **영상 소리 녹음 시작**을 누르고 내부 플레이어에서 영상을 재생합니다. 영상 파일을 다운로드하지 않으며 재생되는 시간만큼 녹음합니다.

## 녹음과 저장 취소

녹음을 잘못 시작했거나 최종 저장을 기다리지 않고 중단하려면 현재 상태에 맞는 취소 버튼을 누릅니다.

| 상태 | 버튼 | 동작 |
| --- | --- | --- |
| 녹음 중 | 녹음 취소 | 입력과 남은 받아쓰기 처리를 중단합니다. |
| 녹음 중지 후 저장 중 | 저장 취소 | 남은 받아쓰기와 최종 음성 병합을 중단합니다. |
| 앱 종료 확인창 | 녹음 취소 후 종료 | 남은 녹음 처리를 취소하고 화면의 작업을 보존한 뒤 앱을 종료합니다. |

취소해도 **이미 저장된 음성과 받아쓰기는 유지합니다**. 아직 처리·저장하지 않은 구간의 완성을 보장하지는 않습니다. 취소한 작업의 늦은 결과가 새 녹음에 적용되지 않도록 처리합니다. 취소가 완료되면 새 녹음을 시작합니다.

## 기록 목록과 전사 검토

**전체 기록**, **중요 기록**, **검토할 기록**에서 기록을 찾습니다. 목록의 별표 버튼으로 중요 표시를 바꾸며, 제목 검색과 최신순·오래된 순 정렬을 지원합니다. 기록을 선택하면 받아쓰기와 회의록을 다시 엽니다.

**받아쓰기**에서 **검토본**과 **최초 원문**을 전환합니다. **원문 함께 보기**로 대조하고, 문장이나 재생 버튼을 눌러 해당 구간의 원음을 확인합니다. 직접 수정한 문장은 별도 `reviewed_text`로 저장하며 최초 원문은 유지합니다.

**검색 · AI 보정 · 참여자 설정**을 펼쳐 검색과 보정 옵션을 조정합니다. AI 보정에서 숫자가 달라지면 원본 녹음을 확인하라는 안내를 표시합니다. 회의 용어·단어장은 AI 보정에만 참고하며 최초 받아쓰기와 원음 복구에는 전달하지 않습니다.

원음 재생은 파일 연결·SHA-256·시간정보를 확인한 뒤 구간 단위로 수행합니다. 저장 음성 재전사는 체크포인트를 사용하며, 원음·모델·용어가 달라지면 기존 체크포인트를 재사용하지 않습니다.

## 요약·회의록·내보내기

실시간 요약은 기본적으로 꺼져 있습니다. 화면에서 켜면 확정된 받아쓰기를 선택한 AI로 보내 요약을 갱신합니다. **회의록 정리하기**에서는 내용을 확인한 뒤 회의록을 생성합니다. 처리 중 예상 남은 시간과 진행 상황을 표시하며, 같은 내용·모델로 재시도할 때 저장된 중간 결과를 재사용합니다.

AI 결과는 초안입니다. 원음·최초 원문·직접 수정본·AI 보정본을 구분해 확인합니다. 요약 모델을 연결하지 않아도 녹음과 최초 받아쓰기는 동작합니다.

- **TXT**: 최초 원문 또는 선택한 AI 보정본을 저장합니다.
- **JSON**: 원문·검토본·회의록·재개 상태를 저장합니다.
- **Markdown**: 회의록을 저장합니다.

기록 저장·불러오기·내보내기는 최대 20MB를 지원합니다. 기본 내보내기 폴더는 문서 폴더의 `Stream-Record/Exports`입니다.

## 동봉 모델과 AI 연결

한국어 받아쓰기용 다국어 Whisper `small-q5_1`을 동봉합니다. 기존에 선택한 정상 다국어 모델을 우선 유지하며, 동봉 모델을 사용할 때 파일 크기와 SHA-256을 확인합니다. 동봉 파일은 `ggml-small-q5_1.bin`이며 크기는 190,085,487바이트입니다. 요약용 대형 언어모델은 동봉하지 않습니다.

**AI 연결**에서 Ollama, 내장 GGUF, OpenAI 호환 서버, OpenCodex·OpenClaw·OpenCode 연결, OpenRouter, OpenAI·Anthropic API와 공식 ChatGPT 로그인을 설정합니다. 실제 제공 모델과 사용 가능 여부는 해당 계정·서비스 응답에 따릅니다. 로컬 모델은 이 PC에서 처리하고 외부 연결 모델은 설정한 서버로 전사문을 전송합니다. localhost 주소도 외부 서비스로 중계할 수 있으므로 실제 전송 위치를 확인합니다. 인증정보는 Windows 사용자 DPAPI로 보호합니다.

녹음이 끝난 뒤 **화자 분석**을 실행하면 동봉 Nemotron 런타임으로 저장 음성을 분석합니다. 원문을 바꾸지 않고 시간 겹침에 따라 화자 번호를 표시합니다. 녹음 중 실시간 화자 스트리밍은 지원하지 않습니다.

## 개발과 빌드

개발 소스는 `app/`에 있습니다. Node.js 20.9 이상, npm, Rust/Cargo, Visual Studio C++ Build Tools, CMake, LLVM/Clang과 Vulkan SDK가 필요합니다. 한국어 모델·FFmpeg·ONNX Runtime 등 고정 리소스를 준비한 뒤 빌드합니다. 모델과 실행 바이너리는 소스 ZIP에 포함하지 않습니다.

```powershell
# 프로젝트 루트에서 환경 확인
node setup.mjs doctor
cd app/frontend
npm run test:stream-record
node tests/stream-record-ui.cjs
npm run typecheck
# v0.8.0과 같은 Vulkan 지원 Windows 빌드
npm run tauri -- build --config ../../tools/tauri.gpu-release.conf.json -- --features vulkan
```

디자인 기준은 [DESIGN.md](DESIGN.md), 변경 이력은 [RELEASE_NOTES.md](RELEASE_NOTES.md)를 참고합니다. 소스 수정, 설치 파일 생성, 설치본 교체와 GitLab 게시는 각각 확인합니다.
